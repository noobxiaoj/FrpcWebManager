#### v0.9.2 (2026-04-08)

> **Translated by Codex**

##### 🎉 Summary
* Added a standalone server detail page and server edit modal
* Added pause, start, restart, and other process control capabilities for servers
* Improved runtime log filtering and server status display, and added an i18n solution for some logs

##### ✨ Key Features
* Supports entering the standalone server detail page to view server address, process port, creation time, port count, uptime, related tasks, and runtime logs
* Supports editing server information directly on the server detail page, and keeps the related-task prompt and confirmation flow before deletion
* Supports pausing, resuming, and restarting servers; after pausing, tasks will be prevented from automatically starting the frpc process again, avoiding unintended recovery of a running frpc process
* Adds more detailed server status indicators, supporting online, offline, no task, paused, fault, and suspected abnormal states
* Supports runtime log category filtering, and optimizes log handling during pause and restart scenarios
* Adds Chinese and English support for the home page, server detail page, task forms, task detail page, about page, and some logs
